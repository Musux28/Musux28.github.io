# Antonio Musumeci — Cybersecurity Portfolio

**Live site:** https://musux28.github.io

Personal portfolio of Antonio Musumeci, M.S. Cybersecurity candidate at the University at Albany (SUNY) and NSA-sponsored research intern.

## The concept: one mind, two hemispheres

The site is built around an animated neural brain:

- **Left hemisphere — Red Team:** offensive projects and attack analysis (kill chains, exploitation labs, attack simulation).
- **Right hemisphere — Blue Team:** detection, digital forensics and incident response.
- **Core — Research:** the bridge between the two, from formal verification of cryptography to AI-generated specifications.

Incoming "threats" are intercepted by the brain in real time. Click a hemisphere to open its projects.

## Featured work

- **NSA research — Cryptography & Formal Verification:** Cryptol, SAW, Isabelle, Rocq, Z3 on AWS EC2 + Docker
- **NSA INSuRE — AI-generated formal specs in Lean 4:** 354 tests, 14 functions, 100% verified
- **ELK SIEM lab:** Elasticsearch, Kibana, Fleet, custom detection rules → [repo](https://github.com/Musux28/elk-siem-project)
- **Windows Registry forensics:** NTUSER.DAT recovery with FTK Imager and Python → [repo](https://github.com/Musux28/ntuser-recovery-project)
- **50°C Inside the Freezer:** Red Team / Blue Team analysis of the November 2026 attacks on European supermarket refrigeration

## Built with

A single self-contained `index.html`: HTML, CSS and vanilla JavaScript with the Canvas API. No frameworks, no build step, no tracking.
